## VideoTube Backend API
A full-featured YouTube-like backend API built with Node.js, Express, MongoDB, JWT, and Cloudinary.

### What I Built
This started as a guided project covering db and project setup, auth, file uploads, and core models.
I then independently completed the remaining 60% of features including:
- [x] Video, Comment, Like, Subscription, Playlist, Tweets, Watch history controllers
- [x] Aggregation pipelines for watch history, channel stats

### Tech Stack
Node.js, Express, MongoDB, Mongoose, JWT, Cloudinary, Multer
